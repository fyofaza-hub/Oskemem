# Oskemen Culture

Социальный гид по Өскемену (Усть-Каменогорску): места, события, маршруты и городская лента в одном интерфейсе. Продуктовый MVP по мотивам презентации `oskemen_culture.pptx`.

Приложение работает **локально без бэкенда**: данные хранятся в `localStorage`, при первом открытии автоматически включается демо-профиль. Supabase подключён как необязательный слой на следующий этап — см. раздел [«Supabase»](#supabase-необязательно).

## Быстрый запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`.

Другие команды:

```bash
npm run typecheck   # проверка TypeScript
npm run build       # production-сборка в dist/
npm run preview     # локальный предпросмотр собранной версии
```

## Демо-доступ

- Почта: `demo@oskemen.kz`
- Пароль: `demo1234`
- При первом запуске вход выполняется автоматически как **Алина Смагулова**.
- На `/auth` есть кнопка входа в демо-аккаунт и регистрация нового локального пользователя.

Аккаунты, пароли, публикации, комментарии, лайки, черновики и сохранения живут только в текущем браузере. Это не настоящая аутентификация и не защищённое хранение.

## Что реализовано

### Главная

- Премиальный тёмный лендинг с реальными фотографиями Өскемена.
- Быстрые переходы в гид и сценарий «Куда сходить?».
- Подборка мест, маршрутов, публикаций и ближайших демо-событий.
- Модальные карточки мест, постов и событий.
- Адаптивная вёрстка и мобильная навигация.

### Социальная лента

- 9 демонстрационных публикаций от пяти вымышленных профилей.
- Лайки, комментарии, сохранение публикаций.
- Фильтры по категориям, поиск, сортировка, фильтр «сохранённые».
- Создание собственной публикации с выбором места, категории и изображения.
- Детальная карточка публикации с комментариями.
- Empty states и модальные окна.

### Городской гид

- 17 реальных городских точек, координаты и адреса сверены с OpenStreetMap.
- Поиск, фильтры по категориям, сортировка.
- Карточки с тремя вариантами отображения.
- Детальная карточка: описание, адрес, категория, избранное, добавление в маршрут.
- Deep links вида `/guide?place=place-embankment`.
- Явная маркировка иллюстративных фотографий и демо-контента.

### Интерактивная карта

- Leaflet + OpenStreetMap, тёмное оформление тайлов.
- Маркеры мест, выбор точки, карточка места, геолокация.
- Режим готовых маршрутов с линией и списком остановок.
- Deep links `/map?place=...` и `/map?route=...`.
- Корректное поведение карточки места при открытом черновике маршрута.

### Маршруты

- 5 готовых демонстрационных маршрутов.
- Детальная страница с картой, таймлайном, сохранением и копированием.
- Конструктор: добавление точек, сортировка, время, заметки, обложка, автосохранение черновика.
- Сохранение маршрута и шаринг через Web Share API с fallback на буфер обмена.
- «Взять за основу» для готового маршрута.
- Время и дистанция помечены как демонстрационные.

### Афиша

- 7 демонстрационных событий с датами, рассчитанными относительно текущего дня.
- Фильтры по категориям, поиск, «сохранённые», фильтр ближайших 7 дней.
- Детальная карточка события.
- Скачивание `.ics`-файла с пометкой о демо-характере данных.
- Deep links `/events?event=...`.

### Профиль

- Профиль, статистика, публикации, маршруты, избранное, сохранённое.
- Редактирование имени, username, города, bio, интересов и аватара.
- Сохранение настроек в localStorage, сброс демо-данных, выход из аккаунта.
- Вкладки сохраняются в URL (`?tab=routes`, `?tab=favorites`, `?tab=saved`, `?tab=settings`).

### Сценарий «Куда сходить?»

Пять шагов:

1. Компания.
2. Бюджет.
3. Впечатления: подбор мест и сохранение выбранного.
4. Маршрут: порядок, время, сохранение.
5. Готово: ссылка, шеринг, переход к маршруту.

Дополнительно:

- Детерминированный подбор по компании, бюджету и интересам.
- Выбранные места попадают в избранное.
- Если черновик уже существует, перед заменой показывается подтверждение.
- Можно собрать новый вариант, не покидая сценарий.

### Общие элементы

- Тост-уведомления, скелетоны, пустые состояния, ошибки форм.
- Поиск по городу с клавиатурным сокращением `⌘K` / `Ctrl+K`.
- Глобальная панель черновика маршрута.
- Модальные окна с Escape, блокировкой скролла и доступными подписями.
- Адаптивность от 390 px, мобильная нижняя навигация.
- Error boundary.

## Данные и честность контента

- **Места**: 17 реальных точек Өскемена. Адреса, координаты и названия сверены с OpenStreetMap. Часы работы и точные цены сознательно не выдумываются.
- **Фотографии**: часть — реальные кадры Wikimedia Commons (авторы указаны в футере и карточках), часть — иллюстративные изображения Unsplash. Иллюстративные фото не выдаются за снимки конкретных заведений.
- **Пользователи, публикации, комментарии, лайки, маршруты и события** — демонстрационные. Это явно помечено в интерфейсе.
- **События** — примеры афиши, а не подтверждённое расписание. Даты пересчитываются относительно текущей даты. Перед посещением проверяйте информацию у организатора.
- **Время и расстояние маршрутов** — демонстрационные. Дистанция считается по прямой между точками, а не по дорожной сети.
- В интерфейсе нет выдуманных достижений, партнёрств, отзывов, рейтингов, платных тарифов и реальных метрик популярности.

## Supabase (необязательно)

Сейчас **MVP не синхронизируется с Supabase**. Авторизация, публикации, лайки, маршруты и сохранения работают локально. В проекте подготовлены:

- `@supabase/supabase-js` в зависимостях;
- `src/lib/supabase.ts` — ленивый клиент, который возвращает `null`, пока нет переменных окружения;
- `supabase/schema.sql` — схема таблиц, индексов, триггера профиля и RLS-политик;
- `.env.example`.

### Как подготовить проект

1. Создайте проект в [Supabase](https://supabase.com/).
2. Откройте **SQL Editor** и выполните `supabase/schema.sql`.
3. В **Authentication → Providers** включите Email.
4. Скопируйте `.env.example` в `.env.local` и заполните:

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

5. Перезапустите dev-сервер.

Используйте только `anon` key. `service_role` нельзя добавлять в клиентские переменные `VITE_*`.

### Что нужно доделать для реального бэкенда

- Заменить локальные `login/register/logout` на `supabase.auth`.
- Перенести чтение и запись `AppContext` на таблицы `profiles`, `posts`, `routes`, `route_stops`, `favorites` и `saved_*`.
- Загрузить реальные места и события в `places` / `events`.
- Настроить загрузку изображений в Storage.
- Добавить миграции и серверную валидацию.
- Пересмотреть RLS-политики и приватность перед production.

Без этих шагов приложение остаётся полностью рабочим локальным прототипом, а Supabase-клиент не используется.

## Локальные ограничения

- Данные не покидают браузер и не синхронизируются между устройствами.
- Ссылки на маршруты и публикации разрешаются только там, где есть этот `localStorage`. Для настоящего шеринга нужен бэкенд.
- Очистка данных сайта или сброс демо-профиля удаляет созданный контент.
- Пароли хранятся в localStorage в открытом виде — это допустимо только для демо.
- Нет загрузки собственных изображений: можно выбрать одно из предложенных.
- Карта использует публичные тайлы OpenStreetMap и требует интернет. При недоступности тайлов интерфейс остаётся работоспособным, но подложка не загрузится.
- Leaflet-маршруты — прямые линии между точками, не пешеходная навигация.
- Приложение не является официальным сервисом города или организаторов.

## Структура проекта

```text
src/
  components/        UI, карточки, карта, макеты, модальные окна
  context/           AppContext (localStorage) и ToastContext
  data/              места, события, посты, маршруты, пользователи, credits
  hooks/             задержка загрузки, требование авторизации
  lib/               утилиты, .ics, Supabase-клиент
  pages/             все страницы приложения
  types/             доменные типы
supabase/
  schema.sql         необязательная схема бэкенда
public/images/       оптимизированные WebP-изображения
```

## Проверка

```bash
npm run typecheck
npm run build
```

Ручной чек-лист:

- главная → гид → карточка → избранное → черновик;
- лента → лайк → комментарий → создание публикации;
- карта → место → маршрут → deep link;
- конструктор → две точки → сохранение → шаринг;
- афиша → фильтр → событие → `.ics`;
- профиль → настройки → перезагрузка;
- `/plan`: компания → бюджет → два места → маршрут → сохранение → ссылка;
- мобильная ширина 390 px: нижняя навигация, отсутствие горизонтального скролла, модальные окна.
